**README Rosetta** हिंदी में पावरफुल ऑटोमेशन टूल है जो अपने दस्तावेज़ को कई भाषाओं में अनुवाद करने के लिए स्थानीय LLMs का उपयोग करके [Ollama](https://ollama.ai/) के माध्यम से डिज़ाइन किया गया है। यह आपके परियोजना को विश्वभर में एक बार प्राप्त करने की अनुमति देता है जबकि इसमें पूर्ण Markdown फ़ॉर्मैटिंग और दस्तावेज़ संरचना बनाए रखता है।

# भारतीय स्थान
यह प्रोजेक्ट आपको एक विशेष क्षमता प्रदान करता है जिससे आप बिना किसी डेटा लॉस के अपने डेटा को अन्य भाषाओं में स्थानांतरित कर सकते हैं।

README रोसेटा आपके गिटहब प्रोजेक्ट को अंतरराष्ट्रीय बनाने में आपकी मदद करता है और इसके लिए न्यूनतम प्रयास किया जाता है।

- **मल्टी-भाषा समर्थन:** अपने `README.md` को दutzeh लहजों में एक ही समय में।
- **नेविगेशन टेबल:** अपने README के शीर्ष पर स्वचालित रूप से एक नेविगेशन "शिला" (टेबल) जोड़ते, उपयोगकर्ताओं को तेजी से लहजों में बदलाव करने की अनुमति देते।
- **लचीले प्रारूप:**
    - **स्प्लिट मोड (वैकल्पिक):** एक साफ़ परियोजना ढांचे के लिए अलग-अलग फ़ाइलें (उदाहरण के लिए, `README.es.md`, `README.fr.md`) पैदा करता है।
    - **यूनिफाइड मोड (`--no-split`):** सब कुछ अनुवाद को प्रमुख `README.md` फ़ाइल में जोड़ता है, अलग-अलग वेब टिप्पणियों से विभाजित करता है।
- **मार्कडाउन संरक्षण:** नेत्र, सूचियों और कोड ब्लॉक्स की मार्गदर्शन करने के लिए स्मार्ट रूप से प्रबंधित करता है ताकि अनुवादित परिणाम सक्षम रहें और स्थिर रूप से फॉर्मेट्ड बनाए रहें।

```bash
# Translate README.md to Spanish, French, and German
readme-rosetta --langs es fr de
```

### वैश्विक विकल्प

| विकल्प | वर्णन | प्रारंभिक मान |
| :--- | :--- | :--- |
| `path` | स्रोत फाइल या परियोजना निर्देशिका के मार्ग का। | `README.md` |
| `--langs` | लक्षित भाषा कोड की सूची (उदाहरण के लिए, `es fr de`)। | `[]` |
| `--src-lang` | स्रोत भाषा कोड। | `en` |
| `--model` | ओल्लामा मॉडल आईडी का उपयोग करना। | `llama3.2` |
| `--readme` | मुख्य निर्देशिका से रीडमई फाइल के लिए स्रोत मार्ग। | `README.md` |
| `--no-split` | अनुवादों को एक ही फ़ाइल में जोड़ें। | `False` |
| `--dry-run` | प्रक्रिया को निर्धारित करने के लिए बिना फाइल लिखना। | `False` |
| `--verbose` | विवरणात्मक लॉगिंग को सक्षम करें। | `False` |

Sphynx संलग्नता

भाषा को पेशेवर स्तर पर शेड्यूल करें और स्वेच्छा से स्पहिन克斯 अंतरराष्ट्रीय समर्थन की सहायता से।

जब आप रोसेटा के साथ रन करते हैं और रोसेटा_CB_27 फ़्लैग पर चलते हैं, तो रोसेटा मैनुअल:
1.  **शुरुआती ढांचे को सेट करता है:** यदि दिरेक्टरी नहीं है, तो `docs/`.
2.   अंतरराष्ट्रीयकरण को स्वचालित रूप से सेट करता है: `conf.py` में आवश्यक `locale_dirs` और `gettext` सेटिंग्स अपडेट करता है।
3.  **अनुवादित खंडों का पता लगाता है:** रोसेटा_CB_32 पर चलते हुए सभी अनुवाद्य चेतावनियाँ खोजते हैं।
4.  **PO फ़ाइलों का अनुवाद करता है:** एलएमएल को उपयोग करके `.po` फ़ाइलों का अनुवाद करता है, जिसमें Sphinx-सPECिफिक सिंटैक्स की पूर्वांक को ध्यान में रखते हुए। 
5.  **एचटीएमएल बनाता है:** हर टारगेट भाषा के लिए स्वचालित रूप से स्थानीयकरणित एचटीएमएल निर्माण करता है।

```bash
# Setup Sphinx with translations for Spanish and Japanese
readme-rosetta --sphinx --langs es ja
```

## रोहित की गिटबुक समर्थन

प्रामाणिक रूप से एक विविध-भाषा वाली गिटबुक को आसानी से रखरखाव करें।

रोसेटा_सीब_३६ प्रतिलिपि रोसेटा_सीब_३७ फ़ाइल को उत्पन्न करता है जो आपके अनुवादित READMEs को गिटबुक की नेविगेशन के लिए एक मानचित्र के संरचना में मैप करता है।

आत्मसंतुलित लिंक: प्रस्तावना को मुख्य README में लिंक करता है और प्रत्येक अनुवादित संस्करण के लिए सूचकांक तत्व बनाता है।
भाषा नाम: भाषा कोड (जैसे, `es`) को उनकी पूर्ण नामों में (जैसे, `Spanish`) में स्वचालित रूप से परिवर्तित करता है।

```bash
# Generate localized READMEs and a SUMMARY.md for GitBook
readme-rosetta --gitbook --langs hi zh pt
```
